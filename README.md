DontRP - это плагин для серверов Minecraft на базе Paper/Spigot, который добавляет полноценную систему ролевых имен (RP имен), описаний персонажей, команды для текстового отыгрыша, а также гибкую систему цветных ников и кастомизацию броска кубика.

## Возможности

- **Система RP имен**: Установка имени и фамилии для персонажа с проверкой через регулярные выражения.
- **Описания персонажей**: Создание детального описания внешности или характера, доступного для просмотра другим игрокам.
- **Ролевые команды**:
  - `/me <действие>` - Описание действия от первого лица.
  - `/do <описание>` - Описание обстановки или действия от третьего лица.
  - `/try <действие>` - Попытка выполнить действие со случайным исходом (Успешно/Неуспешно).
  - `/todo <действие> * <слова>` - Совмещение действия персонажа с его репликой.
  - `/roll [min] [max]` - Бросок кубика в заданном или стандартном диапазоне.
- **Полная кастомизация чата**: Поддержка PlaceholderAPI прямо в конфигурации сообщений ролевых команд. Вы можете настроить отображение `/me`, `/do` и других команд так, как нужно вашему серверу.
- **Настройки броска кубика**: Изменение минимального и максимального значений по умолчанию через команду или GUI.
- **Система цветных имен**: Выбор цвета для RP имени из списка доступных (настраивается через `rp_colors.yml` и права).
- **Локальный чат**: Ограничение видимости ролевых команд определенным радиусом блоков.
- **Интерактивное меню**: GUI-интерфейс (`/rp settings`) для удобного управления всеми параметрами персонажа.
- **Административный функционал**: Полный контроль над данными, именами и описаниями нарушителей.

## Установка

1. Убедитесь, что ваш сервер использует **Paper** или **Spigot** версии **1.16.5** (или выше).
2. Установите [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) (настоятельно рекомендуется для раскрытия всего функционала).
3. Скачайте последнюю версию плагина из [релизов](https://github.com/Dont65/dontrp/releases).
4. Поместите файл `DontRP.jar` в папку `plugins` вашего сервера.
5. Перезапустите сервер.

## Команды

### Основные команды

| Команда | Описание | Пример |
|---------|----------|--------|
| `/rpname` | Показать свое текущее RP имя | `/rpname` |
| `/rpname <Имя> <Фамилия>` | Установить новое RP имя | `/rpname Иван Петров` |
| `/rpname <игрок>` | Показать RP имя другого игрока | `/rpname Dont65` |
| `/rpname remove` | Удалить свое RP имя | `/rpname remove` |
| `/me <действие>` | Действие от первого лица | `/me улыбается` |
| `/do <описание>` | Описание от третьего лица | `/do На столе лежит книга.` |
| `/try <действие>` | Попытка действия с шансом | `/try открыть заклинившую дверь` |
| `/todo <действие> * <слова>` | Действие вместе со словами | `/todo подходит к столу * Всем привет!` |
| `/roll [min] [max]` | Бросок кубика | `/roll 1 20` |
| `/roll default <min> <max>` | Установить диапазон по умолчанию | `/roll default 1 100` |
| `/description` или `/desc` | Показать свое описание | `/description` |
| `/description set <текст>` | Установить описание персонажа | `/description set Высокий эльф в плаще.` |
| `/description <игрок>` | Показать описание другого игрока | `/description Dont65` |
| `/rp settings` | Открыть интерактивное меню настроек | `/rp settings` |
| `/rp namecolor <цвет> [игрок]` | Установить цвет имени | `/rp namecolor &c Dont65` |
| `/rp reload` | Перезагрузить конфигурацию плагина | `/rp reload` |
| `/rp help` | Показать справку по плагину | `/rp help` |

### Административные команды

| Команда | Описание | Пример |
|---------|----------|--------|
| `/adm rpname <игрок> remove` | Принудительно удалить RP имя игрока | `/adm rpname Dont65 remove` |
| `/adm rpname <игрок> <Имя> <Фамилия>` | Принудительно изменить RP имя игроку | `/adm rpname Dont65 Иван Петров` |
| `/adm description <игрок> remove` | Сбросить описание игрока | `/adm description Dont65 remove` |
| `/adm description <игрок> <текст>` | Изменить описание игрока | `/adm description Dont65 Гном` |

## Разрешения (Permissions)

### Права на использование ролевых команд
| Разрешение | Описание | По умолчанию |
|------------|----------|--------------|
| `dontrp.use.rpname` | Доступ к команде `/rpname` (установка/просмотр) | true |
| `dontrp.use.me` | Доступ к ролевой команде `/me` | true |
| `dontrp.use.do` | Доступ к ролевой команде `/do` | true |
| `dontrp.use.try` | Доступ к ролевой команде `/try` | true |
| `dontrp.use.todo` | Доступ к ролевой команде `/todo` | true |
| `dontrp.use.roll` | Доступ к команде броска кубика `/roll` | true |

### Общие и административные права
| Разрешение | Описание | По умолчанию |
|------------|----------|--------------|
| `dontrp.description.view` | Просмотр описаний других игроков | true |
| `dontrp.description.set` | Возможность установить себе описание | true |
| `dontrp.description.admin` | Администрирование описаний (команды `/adm desc`) | op |
| `dontrp.rpname.view` | Просмотр RP имен других игроков | true |
| `dontrp.rpname.admin` | Администрирование RP имен (команды `/adm rpname`)| op |
| `dontrp.rpname_color.*` | Доступ ко всем цветам ников из конфига | op |
| `dontrp.admin` | Полный доступ ко всем функциям и перезагрузке | op |

## Настройка

### Конфигурационные файлы
Плагин генерирует два файла в своей рабочей директории:
1. `config.yml` — основные настройки, радиус чата и форматы вывода команд.
2. `rp_colors.yml` — конфигурация доступных цветов для меню.

### Кастомизация форматов команд (`config.yml`)
В секцию настроек добавлена поддержка изменения внешнего вида ролевых команд. Вы можете использовать стандартные коды цвета через параграф или амперсанд (`&`), а также любые плейсхолдеры от **PlaceholderAPI** (например, `%dontrp_rpname_colored%`, `%player_name%` и т.д.).

---

## PlaceholderAPI

Интеграция предоставляет следующие переменные для использования в сторонних плагинах (табах, скорбордах, чатах):

| Плейсхолдер | Описание | Результат |
| --- | --- | --- |
| `%dontrp_rpname_full%` | Полное имя и фамилия персонажа | `Иван Петров` |
| `%dontrp_rpname_first%` | Только имя | `Иван` |
| `%dontrp_rpname_last%` | Только фамилия | `Петров` |
| `%dontrp_rpname_adaptive%` | Возвращает RP имя, если оно есть, иначе — обычный ник | `Иван Петров` / `Dont65` |
| `%dontrp_rpname_colored%` | RP имя с установленным цветом | `§cИван Петров` |
| `%dontrp_rpname_color%` | Чистый цветовой код игрока | `&c` |
| `%dontrp_description%` | Описание персонажа | `Высокий эльф.` |
| `%dontrp_description_<ник>%` | Описание конкретного игрока | `%dontrp_description_Dont65%` |

## Сборка из исходного кода

1. Убедитесь, что у вас установлен [Maven](https://maven.apache.org/) и совместимая версия Java (JDK 11-16 или JDK 8 в зависимости от вашего target).
2. Клонируйте репозиторий:

```bash
   git clone https://github.com/Dont65/dontrp.git

```

3. Перейдите в каталог проекта и запустите сборку:

```bash
   cd DontRP
   mvn clean package

```

4. Готовый jar-файл появится в директории `target/`.
